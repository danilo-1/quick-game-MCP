# Brainstorm de conceitos

## Fluxo recomendado

1. Pegue o que o usuário trouxe (tema, sentimento, jogo que ama, restrição).
2. Gere **5 conceitos** usando técnicas diferentes (abaixo), um por técnica.
3. Para cada um: **pitch de 1 linha**, **fantasia do jogador**, **loop em 3 passos**.
4. Peça para o usuário escolher, combinar dois ou rejeitar todos ("o que faltou?").
5. Refine o escolhido com 2–3 variações do pitch e siga para `criar_jogo`.

## Técnicas

- **Verbo primeiro**: escolha um verbo satisfatório (empurrar, puxar, girar, trocar, crescer,
  esconder, ecoar) e construa o jogo em volta dele. *"Você só pode empurrar. Tudo é um puzzle de empurrar."*
- **Mashup**: gênero A + tema B inesperado. *"Tower defense + cozinha: as torres são chefs."*
- **Restrição**: um botão, 60 segundos, sem texto, tudo em uma tela, você é o vilão.
- **Inversão**: troque o papel padrão. *"Você é a masmorra, os heróis invadem."*
- **Fantasia emprestada**: uma profissão ou situação real virar jogo. *"Controlador de tráfego aéreo de dragões."*
- **Sistema + tema**: mecânica conhecida em um contexto emocional. *"Tetris, mas cada peça é uma memória que você guarda antes de mudar de casa."*

## Fórmula de pitch

> **[Protagonista] [verbo principal] [onde/como] para [objetivo], mas [complicação interessante].**

Exemplo: *"Um faroleiro gira a luz do farol para guiar barcos na tempestade, mas cada giro
também revela monstros que acordam com a luz."*

Bom pitch: tem verbo, imagem mental e um gancho. Ruim: só adjetivos ("um jogo épico e imersivo").

## Checagem rápida de cada conceito

- Dá para imaginar **os primeiros 10 segundos** de jogo?
- O verbo principal é divertido **sozinho**, repetido 100 vezes?
- Cabe no prazo do usuário (ver `escopo-e-mvp`)?
- Existe uma imagem forte para a capa?

## Ao apresentar

Use uma lista numerada curta. Marque sua recomendação com o motivo em uma frase. Não despeje
mais de 5 opções: escolha fica difícil.
